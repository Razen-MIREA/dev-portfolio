# Портфолио разработчика — шаблон на Bootstrap 5

Готовый статический сайт-портфолио: пять страниц, тёмная и светлая темы,
адаптив от 320 px, форма обратной связи с валидацией. Весь контент лежит в одном
файле `js/data.js` — чтобы поставить свои данные, править HTML не нужно.

- **Только фронтенд:** HTML, CSS, JavaScript, Bootstrap 5.3. Никакой сборки, npm и бэкенда.
- **Работает офлайн:** Bootstrap подключён локально из `assets/vendor/`, иконки — встроенный SVG-спрайт.
- **Без внешних зависимостей, кроме шрифтов:** Inter, Instrument Serif и JetBrains Mono тянутся с Google Fonts; при недоступности сети браузер подставит системные шрифты, вёрстка не поедет.

## Как заменить данные

Откройте `js/data.js`. Все ключи соответствуют блокам на страницах:

| Ключ | Что задаёт |
| --- | --- |
| `meta` | Заголовок и описание по умолчанию, год в копирайте |
| `brand` | Имя, роль, монограмма в навбаре |
| `nav` | Пункты меню |
| `cta` | Кнопка «Обсудить задачу» в шапке |
| `socials` | GitHub и Telegram (иконка + ссылка) |
| `hero` | Главный экран: статус, имя, позиционирование, текст, кнопки, фото, три факта |
| `aboutShort` | Блок «Обо мне» на главной: лид, абзацы, бейджи, кнопка |
| `about` | Страница «Обо мне»: факты, путь, образование, навыки, интересы, принципы |
| `projects` | Проекты: карточки, страницы кейсов, галереи |
| `projectsPage` | Заголовок и тексты страницы «Проекты» |
| `contacts` | Email, телефон, карточки контактов, тексты формы |
| `footer` | Описание, колонки ссылок, копирайт |

## Как добавить проект

Скопируйте объект в массив `projects` и поменяйте значения:

```js
{
  slug: "my-project",              // латиницей; попадает в ссылку project.html?p=my-project
  title: "Название проекта",
  category: "Внутренний продукт",  // по этим значениям строится фильтр
  year: "2024",
  featured: true,                  // true → проект попадёт в «Избранное» на главной
  cover: "assets/img/project-1.svg",
  short: "Одно предложение для карточки в списке.",
  description: "Развёрнутое описание (используется как запасной вариант).",
  tech: ["React", "TypeScript"],
  demo: "https://example.com",     // пустая строка — кнопка не появится
  repo: "https://github.com/you/repo",
  role: "Frontend-разработчик",
  task: "В чём была проблема и почему её нужно было решать.",
  solution: "Что именно вы сделали и какие решения приняли.",
  result: "Что получилось. Если результат не измеряли — так и напишите.",
  facts: [                          // необязательно; блок внизу «Результата»
    { label: "Пользователей", value: "≈100" }
  ],
  gallery: [                        // необязательно; скриншоты с лайтбоксом
    { src: "assets/img/shot-1.svg", caption: "Подпись к экрану" }
  ]
}
```

## Форма обратной связи

Сейчас форма **имитирует** отправку: проверяет поля, показывает индикатор и сообщение
об успехе, но никуда не отправляет данные. Это сделано специально — у статического
сайта нет серверной части.

Точка подключения — функция `submitContactForm(data, ui)` в конце `js/app.js`.
Замените в ней `setTimeout` на реальный запрос:

```js
function submitContactForm(data, ui) {
  const { submit, spinner, submitText, success, error, form, cfg } = ui;

  submit.disabled = true;
  spinner.classList.remove("d-none");
  submitText.textContent = cfg.sendingLabel;

  fetch("https://formspree.io/f/ВАШ_ID", {   // или ваш собственный эндпоинт
    method: "POST",
    headers: { Accept: "application/json" },
    body: data
  })
    .then((res) => {
      if (!res.ok) throw new Error("HTTP " + res.status);
      success.classList.remove("d-none");
      success.scrollIntoView({ behavior: "smooth", block: "center" });
      form.reset();
    })
    .catch(() => {
      error.classList.remove("d-none");
    })
    .finally(() => {
      submit.disabled = false;
      spinner.classList.add("d-none");
      submitText.textContent = cfg.submitLabel;
    });
}
```

## Что умеет

- **Навигация:** фиксированная шапка с подсветкой активного пункта, полоса прогресса чтения, offcanvas-меню на телефоне.
- **Главная:** крупный вводный блок, блок «Обо мне» с бейджами, избранные проекты, блок связи.
- **Проекты:** фильтр по категориям и поиск с задержкой ввода; пустой результат показывается текстом.
- **Страница проекта:** задача → решение → результат, таблица фактов, липкая боковая панель, галерея с лайтбоксом (стрелки ← → на клавиатуре).
- **Обо мне:** путь в виде таймлайна, образование, навыки по группам без процентов, принципы работы. Страница корректно печатается в PDF.
- **Контакты:** карточки контактов и форма с живой валидацией.
